## 四、修掉的坑（按价值排序）

### 坑 1：文章列表点进去是 404

**症状**：笔记列表、首页文章卡片，点进去都打不开。地址栏变了，页面是 404。

**根因**：链接写的是 `/blog/open-banking`，少一个结尾斜杠。构建用的是 `build.format: 'directory'`，页面实际落在 `/blog/open-banking/index.html`。

```
404  /blog/open-banking      ← 列表页点的就是这个
200  /blog/open-banking/     ← 多一个斜杠才对
```

**这个问题是全站性的**，导航里的 `/blog`、`/lab`、`/about` 全都少了斜杠。

**为什么测试全绿却没发现**：断言只检查了 `location.pathname`。跳到 404 页时，地址栏照样是对的，所以测试通过。这是典型的假通过。

**修复**：
- 在 `src/utils/format.ts` 里加了 `postUrl()` 和 `tagUrl()`，所有站内链接统一走它们
- 导航、首页、列表页、详情页、分类页、404 页里的 20 多处裸斜杠写法全部改掉
- `astro.config.mjs` 明确写上 `trailingSlash: 'always'`
- `lint-links.mjs` 新增一类检查：目标是个目录但没写结尾斜杠，直接报错
- `smoke.mjs` 的导航断言改成**检查目标页的正文渲染出来没有**，404 页无法再蒙混过关

**防回归**：现在有三道关卡。构建时索引页会校验文件存在性，`lint-links` 扫构建产物，`smoke` 真实点一遍。

### 坑 2：Astro 作用域样式对动态元素静默失效

**症状**：任务清单做出来第一版，列表项排版彻底散掉，复选框、正文、操作按钮竖排堆叠。

**根因**：Astro 的 `<style>` 会编译成 `.cls[data-astro-cid-xxxx]` 这种形式，那个属性只加给**模板里写死的元素**。任务列表是用 `innerHTML` 拼出来的，拿不到属性，对应样式全部落空。**而且一个字都不报错。**

构建产物里一眼能看出问题：

```bash
grep -oE '\.task[^{]*\{[^}]*\}' dist/_astro/*.css
# .task[data-astro-cid-unyx5r4r]{...}   ← 动态生成的 .task 匹配不上
```

**修复**：动态元素的样式改成作用域内的 `:global()`，挂在模板里的父元素下面，既能命中又不会外泄。

```css
.tasks :global(.task) { display: flex; }   /* 对 */
.task { display: flex; }                    /* 错 */
```

顺手修掉了搜索面板一个一直没查出原因的老问题：`.palette__item` 那一组也是动态建的，之前表现为「标题和分类黏在一起」。

**防回归**：`smoke.mjs` 加了两条排版断言，直接读 `getComputedStyle` 和元素的相对位置。这类 bug 是静默的，只能靠视觉回归兜住。

### 坑 3：合成事件不触发浏览器默认行为

测试里用 `new Event('submit')` 提交表单，`<dialog method="dialog">` 不会触发关闭语义，测试一直失败但功能其实是好的。改成真实点击 `button.click()`，同时在页面里显式补一句 `if (sheet.open) sheet.close()`，两边都不依赖默认行为。

### 坑 4：构建产物里的 HTML 实体导致死链误报

Astro 会把属性里的 `&` 序列化成 `&#38;`，浏览器解析时会正确还原，但纯文本扫描器会把它当成文件名的一部分，于是 `let&const.html` 这类文件全被误报。在扫描器里加了一步实体解码。

### 坑 5：触摸设备上操作按钮点不到

任务清单的「详细 / 删除」按钮原本靠 `:hover` 才显示。触摸设备没有 hover，按钮永远出不来。加了 `@media (hover: none)` 让它在触摸设备上常显。
