## 问题

掷两个六面骰子，点数和是**偶数**的概率有多大？

这个问题简单到能口算，但拿它开头正合适——因为它能用两种完全不同的办法算，而且答案一样。对比着看，就知道蒙特卡洛到底在干什么。

## 办法一：把组合全列出来

两个骰子各有 6 面，所有可能是 6 × 6 = 36 种。把和为偶数的数一遍就行。

```julia
const FACES = 1:6

numSol = sum(iseven(i + j) for i in FACES, j in FACES) / length(FACES)^2
```

这里有个 Julia 特有的写法值得说：

```julia
for i in FACES, j in FACES
```

**逗号分隔多个范围，会展开成笛卡尔积**。也就是说 `i` 取 1 到 6 的同时，`j` 也把 1 到 6 走一遍，一共跑 36 次。这和写成两层嵌套循环是一回事，但紧凑得多。

`iseven(x)` 是 Julia 自带的判断偶数的函数，返回 `true` 或 `false`。求和的时候 `true` 当 1、`false` 当 0，所以 `sum` 出来的就是偶数和的组合数。

算出来是 **18**，18/36 = **0.5**。

## 办法二：真的掷一百万次

不推导，直接模拟：

```julia
const N = 10^6
rng = MersenneTwister(42)

mcEst = sum(iseven(rand(rng, FACES) + rand(rng, FACES)) for _ in 1:N) / N
```

`rand(rng, FACES)` 从 `FACES` 里随机取一个数，取两次相加，判断是不是偶数。做 N 次，数出其中偶数的比例。

跑出来是 **0.500023**，和精确值只差 0.000023。

真实的终端输出：

```
理论值（数组合）      = 0.500000
蒙特卡洛（1000000 次）  = 0.500023
两者相差              = 0.000023
```

## 两种办法的对比

| | 办法一 | 办法二 |
|---|---|---|
| 结果 | 0.500000 | 0.500023 |
| 耗时 | 微秒级 | 约 0.1 秒 |
| 需要懂推导 | 需要 | 不需要 |
| 能推广到复杂问题 | 常常不能 | 可以 |

**办法二慢了几万倍，结果还差了一点点**——那为什么还要用它？

因为办法一**只在这个问题里管用**。要是问「掷五个骰子，和能被 3 整除的概率」，组合推导就开始变复杂了；再复杂一点，比如密码那个问题，根本没有简单公式。而办法二**照搬就能用**，只是要多跑几次。

## 一个顺带的发现

为什么答案恰好是 0.5？

因为骰子面数是 6，是偶数。奇偶各 3 个面，`i` 和 `j` 同奇偶时和为偶数，3×3 + 3×3 = 18 种。

**如果骰子是 5 面**，答案就不是一半了，会变成 13/25 = 0.52。可以改一下 `FACES = 1:5` 自己试试。

## 关于随机种子

代码里写了 `MersenneTwister(42)`,这是固定随机种子，**保证每次跑结果都一样**。做实验的时候很有用——不然每次数字都在跳，没法对比。

想每次都拿到不同的结果，去掉种子就行：

```julia
rng = Random.default_rng()
```
