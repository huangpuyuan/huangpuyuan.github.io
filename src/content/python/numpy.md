## 为什么先学 NumPy

Pandas 建在 NumPy 上，sklearn 建在 NumPy 上，几乎所有 Python 数据工具都建在 NumPy 上。
它解决的核心问题是：**让数据成块地参与运算，而不是一个数一个数地算**。

这个区别有多大？看手写 KNN 里的一行：

```python
dist_squared = np.sum(data**2, axis=1).reshape(-1, 1) + np.sum(data**2, axis=1) - 2 * np.dot(data, data.T)
```

这一行算出了 10 个点**两两之间**的平方距离，也就是 100 个数字。
用普通 Python 得写两层循环、累加 100 次。

## 一、造数组：六种常用方式

```python
import numpy as np

array_1d = np.array([1, 2, 3, 4, 5])          # 从列表造
array_2d = np.array([[1, 2, 3], [4, 5, 6]])   # 二维
zeros_array = np.zeros((2, 3))                # 全零
ones_array = np.ones((2, 3))                  # 全一
arange_array = np.arange(0, 10, 2)            # 等差（指定步长）
linspace_array = np.linspace(0, 1, 5)         # 等分（指定个数）
```

实测输出：

```
一维数组: [1 2 3 4 5]
二维数组:
 [[1 2 3]
 [4 5 6]]
全零数组:
 [[0. 0. 0.]
 [0. 0. 0.]]
全一数组:
 [[1. 1. 1.]
 [1. 1. 1.]]
等间隔数组: [0 2 4 6 8]
线性空间数组: [0.   0.25 0.5  0.75 1.  ]
```

**`arange` 和 `linspace` 的区别值得记一下**：一个是「步长固定，个数不定」，一个是「个数固定，步长不定」。

- `np.arange(0, 10, 2)` → 从 0 开始每次加 2，到 10 之前停 → `[0 2 4 6 8]`（5 个数）
- `np.linspace(0, 1, 5)` → 从 0 到 1 **均匀切 5 份** → `[0, 0.25, 0.5, 0.75, 1]`（步长 0.25）

画函数图像的时候要用 `linspace`——因为你控制的是「采多少个点」，而不是「每次走多远」。

还有个小细节：`np.zeros((2,3))` 出来的是 `0.`（浮点）而不是 `0`（整数）。
NumPy 造填充数组时默认用浮点类型，因为浮点更通用。

## 二、索引与切片

```python
print("第一个元素:", array_1d[0])
print("最后一个元素:", array_1d[-1])
print("第二行:", array_2d[1])
print("第一行第二列元素:", array_2d[0, 1])
print("切片:", array_1d[1:4])   # 从索引 1 到 3
```

```
第一个元素: 1
最后一个元素: 5
第二行: [4 5 6]
第一行第二列元素: 2
切片: [2 3 4]
```

**二维索引用逗号不用嵌套方括号**：写 `array_2d[0, 1]` 而不是 `array_2d[0][1]`。
两种都能用，但前者更快（一次定位），也更符合 NumPy 的表达习惯。

**`-1` 表示倒数第一个**：`array_1d[-1]` 是 5。这个 Python 列表也有。

**切片「含头不含尾」**：`array_1d[1:4]` 取的是索引 1、2、3，**不含 4**。
输出 `[2 3 4]` 印证了这点。这个规则和 Python 列表一致，但刚开始特别容易写错。

## 三、数组运算：不用写循环

```python
array_sum = array_1d + 10
array_product = array_1d * 2
```

```
加法结果: [11 12 13 14 15]
乘法结果: [ 2  4  6  8 10]
```

`array_1d + 10` 直接给**每个元素**加 10。不用循环，不用列表推导。
这叫**向量化运算**，是 NumPy 最核心的便利。

聚合函数也一样：

```python
print("数组和:", np.sum(array_1d))
print("数组均值:", np.mean(array_1d))
print("数组最大值:", np.max(array_1d))
```

```
数组和: 15
数组均值: 3.0
数组最大值: 5
```

## 四、ufuncs 与广播

这一节是 NumPy 真正的门槛。先说 ufuncs（通用函数）——就是**逐个元素作用的函数**：

```python
array = np.array([1, 2, 3, 4, 5])
print("平方:", np.square(array))
print("平方根:", np.sqrt(array))
print("正弦:", np.sin(array))
print("大于3的布尔数组:", np.greater(array, 3))
```

```
平方: [ 1  4  9 16 25]
平方根: [1.         1.41421356 1.73205081 2.         2.23606798]
正弦: [ 0.84147098  0.90929743  0.14112001 -0.7568025  -0.95892427]
大于3的布尔数组: [False False False  True  True]
```

一个函数作用在 5 个数上，一次拿到 5 个结果。注意最后一行——比较运算也是 ufunc，
返回的是**布尔数组**而不是单个真假值。

### 广播：形状不同也能算

现在看这个例子：

```python
a = np.array([1, 2, 3])           # 形状 (3,)
b = np.array([[10], [20], [30]])  # 形状 (3,1)

result = a + b
```

```
广播结果:
 [[11 12 13]
 [21 22 23]
 [31 32 33]]
```

`a` 有 3 个元素，`b` 是 3 行 1 列，形状明明对不上，却算出了一个 3×3 的结果。

**这就是广播（broadcasting）**。规则是：NumPy 比较两个数组的形状，**从最右边一位开始往左对**，
遇到长度是 1 的维度就把它「拉长」到和另一边一样。

具体到这一步：

```
a:  (3,)    →  看成 (1, 3)  →  拉成 (3, 3)
b:  (3,1)   →  看成 (3, 1)  →  拉成 (3, 3)
```

`a` 沿行方向复制 3 次，`b` 沿列方向复制 3 次，然后逐元素相加：

```
        a→  [1  2  3]        b↓         结果
        [1  2  3]         [10]      [10+1  10+2  10+3]   [11 12 13]
        [1  2  3]    +    [20]  =   [20+1  20+2  20+3] = [21 22 23]
        [1  2  3]         [30]      [30+1  30+2  30+3]   [31 32 33]
```

**广播不真的复制数据**——NumPy 只是在计算时把长度 1 的维度「虚拟展开」，
内存里还是那 3 个数和那 3 个数。所以它既省内存又快。

手写 KNN 那行距离公式就靠广播和矩阵乘法，一行顶两层循环。

## 五、比较、掩码与花式索引

```python
array1 = np.array([1, 2, 3, 4])
array2 = np.array([3, 2, 1, 0])

print("相等比较:", array1 == array2)
print("大于比较:", array1 > array2)
print("小于等于比较:", array1 <= array2)
```

```
相等比较: [False  True False False]
大于比较: [False False  True  True]
小于等于比较: [ True  True False False]
```

比较是一对一的（相同位置比较），结果还是布尔数组。拿这个布尔数组当**掩码**，就能筛元素：

```python
array = np.array([1, 2, 3, 4, 5, 6])
mask = array > 3
filtered_array = array[mask]
print("大于3的元素:", filtered_array)
```

```
大于3的元素: [4 5 6]
```

这两步可以合成一行：`array[array > 3]`。看着像魔法，其实就是「先算掩码、再用它取子集」，
只是省掉了中间变量。

另一种打法是用**索引数组**（花式索引）：

```python
array = np.array([10, 20, 30, 40, 50])
indices = [0, 2, 4]
print("花哨的索引结果:", array[indices])
```

```
花哨的索引结果: [10 30 50]
```

传一个**列表**进去，拿回来的是「这些位置上的元素」。和切片不同，花式索引可以做任意挑选，
甚至重复取同一个位置。

## 六、排序

```python
array = np.array([3, 1, 2, 5, 4])
print("排序结果:", np.sort(array))
print("排序索引:", np.argsort(array))
```

```
排序结果: [1 2 3 4 5]
排序索引: [1 2 0 4 3]
```

`np.sort` 返回排好序的数组。但 `np.argsort` 更有意思——它返回的是**「排好序之后，
每个位置原来是谁」**：

```
原数组:        索引 0 1 2 3 4
              值   3 1 2 5 4
排序后:        值   1 2 3 4 5
              来自 1 2 0 4 3    ← 这就是 argsort 的结果
```

**为什么需要「索引」而不是「值」？** 因为想知道排序后每个元素在原数组的什么位置。
手写 KNN 里就是靠这个找最近邻的：

```python
distances = np.linalg.norm(data - query_point, axis=1)   # 5 个距离
sorted_indices = np.argsort(distances)                   # 按距离排序，拿到的是索引
nearest_indices = sorted_indices[:K]                     # 取前 K 个
nearest_labels = labels[nearest_indices]                 # 用索引去取对应标签
```

**先拿到「谁最近」的索引，再用索引去取标签**——这个套路在数据处理里非常常见。

## 七、结构化数组

最后这个用得少，但值得知道：

```python
dtype = np.dtype([('name', 'U10'), ('age', 'i4'), ('height', 'f4')])
structured_array = np.array([('Alice', 25, 5.5), ('Bob', 30, 6.0)], dtype=dtype)

print("姓名:", structured_array['name'])
print("年龄:", structured_array['age'])
print("身高:", structured_array['height'])
```

```
姓名: ['Alice' 'Bob']
年龄: [25 30]
身高: [5.5 6. ]
```

一个数组里能塞不同类型（`U10` 是长度 10 的字符串，`i4` 是 32 位整数，`f4` 是 32 位浮点），
按字段名访问。相当于**没有文件头的一行 CSV**。

实际做数据分析时基本不用它——Pandas 的 DataFrame 就是它的高级版，更灵活。
这里知道有这么个东西就够了。

## 小结

NumPy 的四个核心概念，按重要性排：

| 概念 | 一句话 |
|---|---|
| **向量化** | 运算作用在整块数据上，不用写循环 |
| **广播** | 形状不同也能算，从右往左对齐，长度 1 的维度自动展开 |
| **掩码** | 比较得到布尔数组，拿它筛元素 |
| **argsort** | 排序拿到的是「谁在哪」，不是「值是多少」 |

其中**广播**是最值得花时间弄懂的——它是「为什么别人一行代码能顶我十行」的答案。
